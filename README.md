🚀 Job Scraper Tool

An automated and customizable job-scraping tool that collects job postings from multiple job boards and career pages. It extracts key details—such as job title, company, location, salary, and application link—and exports them in structured formats for easy analysis.

📌 Features

🔍 Multi-site scraping (job boards & company career pages)

🎯 Keyword, location, and role filtering

🔄 Automatic scheduling (cron or built-in scheduler)

🧹 Duplicate detection & data cleaning

📤 Export to CSV, JSON, or database

🛡️ Error handling & request throttling

⚙️ Easy to configure and extend
